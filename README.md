How to install:

1) Download the resource pack by clicking "Code", then "Download Zip".
2) Once it downloads, open File Explorer and open "Downloads". Right click the zip file, and click "Extract All". It should create a folder with the contents of this Github page.
3) Open the new "tinytotem-main" folder. Inside it is the actual texture pack folder, "Tiny Totem".
4) Open Minecraft Java.
5) Go to Options > Resource Packs > Open Folder.
6) Copy and paste the "Tiny Totem" folder into this folder, then close the window. If the resource pack doesn't appear on the list, try restarting Minecraft.
7) Enjoy cute and adorable and tiny (maybe too tiny) totems!
